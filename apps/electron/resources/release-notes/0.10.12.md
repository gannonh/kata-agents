# v0.10.12

## Features

- **Worktree V2 enabled by default** — Named managed worktrees, server-owned roots, snapshot-backed lifecycle management, checkout handoff, and eligible isolated conversation forks are now available by default alongside Git/GitHub V1. Set `KATA_FEATURE_WORKTREE_V2=0` on the workspace-owning server to retain V1-only behavior; provider-specific handoff and native-fork capabilities remain gated by adapter support ([#17](https://github.com/gannonh/kata-agents/issues/17)).
