# v0.10.6 — Welcome to Kata Agents

This is the first Kata Agents release. What's New starts here and grows with each release.

## Features

- **Redesigned update experience** — The app checks for updates in the background and surfaces an `Update available` pill in the sidebar instead of auto-downloading. Click to download, then `Restart to update` to install on your schedule. A new Settings → About **Update track** selector switches between **Stable** and **Nightly**; the installed build supplies the default, and your choice persists and takes effect immediately. The macOS app menu `Check for Updates…` shows a native up-to-date or failure dialog, and production builds keep an updater diagnostics log for troubleshooting.

## Bug Fixes

- **Reliable macOS auto-update** — macOS update downloads now verify and install correctly. Each release build produces a single-architecture package whose update manifest is computed directly from the published asset, fixing the checksum mismatch and corrupt-download failures that blocked `Restart to update`.
- **Correct update version source** — Settings and the macOS `Check for Updates…` dialog read the installed app version, keeping Stable/Nightly checks consistent with the macOS About panel.
- **Correct macOS app icon sizing** — macOS builds use the `AppIcon.icns` packaging path and bundle Liquid Glass assets correctly.
