Kata Agents is an open-source desktop app, server, and CLI for persistent AI agent sessions. It brings coding-agent workflows into the rest of your work: repositories, issue trackers, Slack threads, local files, internal APIs, and repeatable automations.

## What you can do

- Run coding and non-coding tasks in long-lived sessions.
- Organize sessions with statuses and labels instead of losing context in terminal history.
- Connect external systems through sources.
- Review plans before changes happen.
- Automate recurring work with schedules, labels, status changes, and messaging triggers.

<Tip>
  If you are looking for the in-app configuration docs bundled with the desktop app, they are also synced locally to `~/.kata-agents/docs/` on launch.
</Tip>
