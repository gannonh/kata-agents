---
title: "Preferences"
description: "Understand user preferences that help Kata Agents personalize responses."
keywords: ["preferences", "profile", "timezone", "personalization"]
---

Preferences store user-specific context such as name, timezone, location, and response preferences. They help Kata Agents personalize answers without repeating the same details in every session.

Preferences are stored locally under `~/.kata-agents/preferences.json`.

Only save preferences that the user has explicitly provided or confirmed.
