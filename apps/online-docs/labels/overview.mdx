Labels help you classify, filter, and route sessions. Use labels for priority, project, customer, topic, due date, or automation state.

## Label types

Labels can be simple presence-only tags or typed values.

| Shape | Example | Use it for |
| --- | --- | --- |
| Boolean | `bug` | Simple tags |
| String | `area::docs` | Categories and ownership |
| Number | `priority::3` | Priority or scoring |
| Date | `due::2026-06-30` | Deadlines |
| Link | `issue::https://example.com/issue/1` | External references |

## Automations

Labels can trigger automations when they are added or removed. This makes them useful for triage, notifications, handoffs, and reporting.
