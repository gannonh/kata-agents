# Specs — Roadmap

The remaining rebrand work is consolidated into one complete brand-transition plan. The old Project A/C/D split is superseded by the active spec below; implementation can still ship as multiple smaller PRs under that plan.

## Active

* [2026-07-26-git-github-worktrees-v1-design.md](2026-07-26-git-github-worktrees-v1-design.md): V1 design for Current checkout/New worktree sessions, a Changes review panel with line feedback, safe commit/push/GitHub PR actions, and local/remote worktree lifecycle parity. Status: Approved; **Phase 1 (Start isolated) complete and Phase 2 (Review changes) building** behind `KATA_FEATURE_GIT_WORKSPACE_V1`. Phase 2 landed the Changes header affordance (changed-file count + additions/deletions), a right-sidebar Changes panel (overlay drawer at narrow widths) bound to the focused session, a flat changed-file list with explicit clean/non-Git/binary/oversized/missing/loading/error states, unified/split diff via `ShikiDiffViewer`, diff-line feedback (old/new sides) with a session-scoped pending-comment store, stale-on-fingerprint-change detection, and a single deterministic follow-up send through the existing message pipeline. Renderer subscribes on open / unsubscribes when the last surface closes, with ≤3s coalesced polling → ≤5s external-change bound. See ADR [2026-07-29-server-owned-managed-worktrees.md](../adrs/2026-07-29-server-owned-managed-worktrees.md). Phases 3–4 (commit/push/PR, lifecycle UI) declared in protocol but stubbed.
